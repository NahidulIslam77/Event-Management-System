# Event Management System (C)

## 📖 Description
Event Management System in C that stores events in a text file. Supports adding, viewing, updating, filtering, and deleting events. Demonstrates file handling, arrays, and structures in C with a simple command-line interface.

## ⚙️ Features
- Add new events  
- View all events or filter by date/location  
- Update event details  
- Delete events by name or date  
- Save and load events from `events.txt`  

## 🗂️ File Structure
.
├── events.txt # Stores all event data
├── main.c # Source code
└── README.md # Project description

## 🚀 How to Run
1. Clone the repository:
   git clone https://github.com/YourUsername/event-management-c.git
   cd event-management-c
Compile the program:
gcc main.c -o event_manager
Run the executable:./event_manager
